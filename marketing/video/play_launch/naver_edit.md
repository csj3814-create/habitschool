# 네이버 블로그 수정 안내 — 플레이스토어 출시 영상 넣기

**10-15 사용자가 1~7편 모두 수정 완료.**

네이버 블로그는 브라우저 자동화가 막혀 있어서(blog.naver.com 접속 차단) 사용자가 직접 고친다.
브런치 7편은 10-15에 같은 방식으로 고쳐서 다시 발행해 두었다(영상은 파일로 올림, 표지 이미지 바로 아래).

## 고치는 방법 (글마다 1분)
1. 글 열기 → 오른쪽 위 '수정'
2. **표지 이미지 바로 아래**(표지가 없으면 글 맨 위)에 커서를 두고, 아래 표의 유튜브 주소를 붙여 넣기
   → 스마트에디터가 영상 카드로 바꿔 준다. 카드가 안 생기면 위 도구 막대 '동영상' → 'YouTube 링크'에 주소를 넣는다.
3. **초대 링크(habitschool.web.app/i/7E8HF9) 바로 아래**에 한 줄 추가:
   - 1~4편(습니다체): `→ 안드로이드폰은 이제 플레이스토어에서 '해빛스쿨'을 검색하시면 앱으로 받으실 수 있습니다.`
   - 5~7편(해요체): `→ 안드로이드폰은 이제 플레이스토어에서 '해빛스쿨'을 검색하시면 앱으로 받으실 수 있어요.`
4. '발행' (카테고리·태그는 그대로)
