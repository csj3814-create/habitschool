```
Habit School: Habit Tracker
```

```
Habit tracker for meals, workouts & sleep. Snap a photo, get daily AI feedback.
```

## 붙여 넣은 뒤

- 콘솔 오른쪽 아래 **저장** → 「검토를 위해 변경사항 보내기」. 등록정보만 바뀌면 보통 하루 안쪽에 반영된다.
- 2~3주 뒤 플레이 콘솔 → 통계 → 「스토어 등록정보 방문자 — 검색어」에서 habit tracker 유입을 본다.
