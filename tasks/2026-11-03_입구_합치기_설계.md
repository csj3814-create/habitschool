# 입구 합치기 — 처음 온 사람은 `/` 에서도 소개 페이지를 본다 (설계안)

2026-11-03. 구현 전에 대표 확인을 받는다.

## 한 줄 요약

골든타임 영상 링크(`https://habitschool.web.app/`)로 **처음 온 사람에게는 로그인 화면 대신 소개 페이지**를 보인다.
주소는 바꾸지 않는다(대표: 주소 뒤에 뭘 붙이면 피싱 걱정을 만든다).

## 지금

- 소개 페이지는 `/welcome` 에서만 보인다(`index.html` head 가 경로를 보고 `ko-landing` 을 붙인다).
- 영상 링크는 `/` 라서, 영상을 보고 온 사람은 소개 페이지 대신 로그인 화면을 본다.
- 9월 기록: 처음 온 사람 467명 중 로그인을 누른 사람 48명(10%).

## 바꾸는 것

### 1. `/` 에서 소개 페이지를 보이는 조건

아래가 **모두** 맞을 때만:
- 이 기기에서 로그인한 적이 없다(로그인 표시 `habitschool-signed-in-hint-v1` 이 없다).
- 주소에 아무것도 붙어 있지 않다. 초대(`?ref=`), 공유(`?focus=`), 알림·메일(`?tab=`, `utm_medium=email`), 둘러보기(`?guest=1`)로 온
  사람은 지금처럼 로그인 화면으로 간다 — 이미 무엇을 하러 온 사람이다.
- 플레이 앱 안이 아니다(`/app`, 앱에서 넘어온 표시). 앱을 깐 사람은 이미 마음먹은 사람이다.
- 한국어 `/` 만. 영어(`/en`)는 그대로.

판단은 지금 `/welcome` 처럼 **첫 화면 전에** head 에서 한다(깜빡임 없음).

### 2. 소개 페이지의 시작 단추

지금 "구글 계정으로 시작하기"·위쪽 "로그인" 은 `/` 로 가는데, 이제 `/` 가 다시 소개 페이지가 되므로
**`/?start=1`** 로 보낸다. `start=1` 이 붙으면 소개 페이지를 건너뛰고 로그인 화면이 바로 뜬다.

### 3. 재는 것

- 소개 페이지를 본 것(`landing_view`)과 시작 단추를 누른 것(`auth_start`, 이미 있음)을 구글 애널리틱스로 남긴다.
- 2~3주 뒤: 처음 온 사람 중 로그인을 누른 비율(지금 10%), 가입자 수.

## 바꾸지 않는 것

- 로그인했던 사람, 초대·공유·알림으로 온 사람, 플레이 앱, 영어 앱 — 지금 그대로.
- `/welcome` 주소도 그대로 둔다(이미 퍼진 링크).
