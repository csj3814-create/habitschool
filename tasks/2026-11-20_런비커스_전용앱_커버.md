# 런비커스 전용 앱 커버 (2026-11-20)

대표: "병의원 전용앱처럼 런비커스 전용앱 커버. 처음 가입할 때 런비커스 소모임에 가입되게, 4주 중 14일 성공하면
런비커스 전용앱을 풀고 해빛스쿨 기본앱으로 돌아갈지 물어본다. 달리기 중심이라 식단·수면 가리고 내 기록·운동·갤러리만."
참가비: 대표 선택 "첫 4주는 면제".

## 흐름

1. 들어오는 링크는 지금 단톡방에 돈 것 그대로: `/?group=runbickers` (초대 `/i/CODE?g=runbickers` 도 같은 값으로 온다).
2. **새로 가입한** 회원이 그 링크를 기다리고 있으면 → 바로 커버를 켜고(`<html class="partner-cover partner-runbickers">`)
   서버 `joinHabitGroup({ groupId: 'exercise-runbickers', partnerCover: 'runbickers' })` 로 모임에 넣는다.
   - 서버가 확인: 계정 만든 지 3일 안, 이 모임의 지난 진행 없음(첫 4주), 회원 문서에 커버가 아직 없음 → 참가비 면제
     (`entryFeeStatus: 'partner_cover_waived'`), `users/{uid}.partnerCover = { id, groupId, status:'active', startedAt, startedDate }`.
   - 조건이 안 맞으면 커버·면제 없이 보통 가입 규칙.
   - 기존 회원이 링크를 누르면 지금처럼 모임 창만 연다(커버 없음).
3. 커버 화면: 탭은 📊 내 기록 · 🏃 운동 · ✨ 갤러리만. 식단·마음·자산 탭 단추를 감추고, 그 탭으로 가려 하면 운동 탭으로.
   머리글에 "🏃 런비커스" 표시. 포인트·기능은 그대로(화면에서 탭만 감춘다).
   가입 안내(첫 기록)는 "식단 사진" 대신 "달리기 기록" — 단추가 운동 탭으로 보낸다. 가입 선물 200P 는 그대로.
4. 4주 안에 14번 → 보상 지급 때 서버가 `partnerCover.completedAt` 을 적는다(onHabitGroupCheckinWritten).
5. 앱을 열 때 `status:'active'` + `completedAt` 이 있고 아직 안 물었으면 창: "해빛스쿨 전체 앱으로 바꿀까요?"
   - 「전체 앱 쓰기」 → `decidePartnerCover({ choice:'release' })` → `status:'released'`, 커버 끔.
   - 「런비커스 앱 그대로」 → `choice:'keep'` → `keptAt`, 커버 유지. 이 뒤로는 프로필에서 언제든 전체 앱으로 바꿀 수 있다.
   - 서버는 완주(`completedAt`) 전에는 release 를 받지 않는다. 단, 모임을 나갔거나 마무리해 모임에 더는 없으면
     완주 전이라도 프로필 「기본형」으로 풀 수 있다(리뷰: 모임 밖에서 커버에 갇히는 길을 막음).
6. 14번을 못 채운 4주가 끝나면 커버는 그대로, 모임 규칙대로 새 4주(참가비 200P)를 시작한다.
