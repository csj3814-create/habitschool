# LE8 건강습관 점수 도입

## 배경

"내 습관이 만성대사질환·암 예방에 얼마나 잘하고 있나"를 하나의 점수로 답하기 위해
AHA **Life's Essential 8 (LE8)** 방식을 도입했다. 기존 대사건강 점수는 인슐린 저항성
개선에 초점을 둔 자체 설계라 국제 근거와 연결되지 않고 암을 다루지 않는다.

세 후보(LE8 / WCRF·AICR / 하버드 5점) 중 LE8을 택한 이유는 앞의 계획서 참조.
핵심은 **신규 사용자 입력 2개(키·흡연상태)만으로 8개 항목이 전부 계산된다**는 것,
그리고 약물 감점에 필요한 고혈압약·당뇨약·고지혈증약 체크박스가 이미 있다는 것.

## 설계에서 신경 쓴 것

**결측 가드.** 생활습관 2개 + 대사지표 2개가 있어야 총점을 낸다. 없으면 "—". 혈압만 잰
사람이 100점을 받는 오해를 막는다. 총점을 숨길 때는 묶음 점수(생활습관/대사지표)도 함께
숨긴다 — 안 그러면 "내 대사지표는 100점"이라는 같은 오해가 되살아난다.

**"모른다"와 "0점"의 구분.** 걸음수도 운동 기록도 전혀 없으면 결측으로 둔다. 0점을 주면
걸음수를 연동하지 않은 사용자의 총점이 부당하게 깎인다.

**중복 계산 방지.** 하루 활동시간은 걸음수 추정분과 운동 기록 추정분을 더하지 않고 큰
쪽만 쓴다. 산책 사진과 걸음수가 같은 활동일 수 있다.

**정직성.** 식단·신체활동·수면은 검증된 계측이 아니라 대체지표다. 항목마다 `*` 를 달고
카드 아래 각주로 설명한다. "AHA 검증 점수"라고 쓰지 않고 "LE8 방식"으로만 쓴다.
개인별 암 위험도 수치는 제시하지 않는다.

**BMI 배점.** 점수는 AHA 표(<25 만점)로 내되, 설명 문구에는 한국인에게 맞는
아시아-태평양 기준(정상 <23)을 병기한다. 배점표를 바꾸면 국제 비교가 깨진다.

## 검증

- `npx vitest run` → **118 파일 / 1165건 통과** (에뮬레이터 테스트 7건 스킵)
- 렌더링 3개 상태(우수 99점 / 개선필요 14점 / 데이터부족 가드)를 실제 모듈·실제 CSS로
  브라우저에서 확인. 라이트·다크 모드 모두 확인. 콘솔 오류 없음.
- 점수 계산 수기 검증: 우수 케이스 (95+100+100+100+100+100+100+100)/8 = 99 ✓
  개선 케이스 (8+0+0+40+30+0+30+5)/8 = 14 ✓ (약물 감점 3종 모두 반영)

## 남은 것 (이번 범위 밖)

- **음주** — LE8에 없어 수집하지 않았다. 암 특화 보조점수를 원하면 첫 번째 추가 항목.
- **WCRF 암예방 보조점수** — 그램·인분 정량이 사진 AI로 안 나온다. 식단 프롬프트에
  `redMeatServing`·`sugaryDrink`·`fiberGramsEstimate` 를 추가하면 사용자 입력 없이 가능.
- **운동 시간·강도 입력** — 신체활동이 추정치로 남는 원인. `summarizeHabitGroupExerciseItem`
  이 이미 `minutes/sets/reps` 를 방어적으로 읽고 있어 잠재 스키마가 있다. 가장 싼 다음 단계.
- **`sleepHours` 는 배포 후 실제 값이 들어오는지 확인해야 한다.** 프롬프트만 고쳤을 뿐이라
  Gemini가 실제로 숫자를 넣어주는지는 수면 사진 한 장을 올려보고 Firestore에서 봐야 한다.
  그 전까지 수면 항목은 기존 `sleepDuration` 문자열 파싱으로 동작한다.

## 2차 (스테이징 피드백 반영)

- 수면이 안 잡힌 원인: `sleepAnalysis` 는 마음 탭의 `🤖 AI 분석` 버튼을 눌러야만 생긴다.
  사진만 올리면 만들어지지 않는다. **점수가 선택적 수동 조작에 의존하고 있었다.**
  → 수면 시간 직접 입력칸 추가. AI 분석이 돌면 빈 칸을 자동으로 채운다.
- 혈중지질은 검사지 업로드가 유일한 경로였다. 콜레스테롤은 가정용 기기로 못 잰다.
  → 프로필에 총콜레스테롤·HDL 직접 입력 추가. 검사지가 있으면 그쪽이 우선.
- 식단 배점 매핑은 LE8 백분위 구간 그대로라 유지. 대신 **간식이 정식 한 끼와 같은
  무게로 평균에 들어가던 것**을 절반으로 낮췄다. 정직하게 기록할수록 손해 보는
  구조는 습관 앱에 해롭다. 같은 데이터로 43 → 54점.
- 점수 구간 눈금자(0/50/80/100)와 구간 의의 문구 추가.
- **빈 항목을 누르면 해당 탭으로 이동해 입력칸을 붉게 표시**한다(`focusLE8Field`).
  입력칸이면 그 칸을, 라디오 그룹처럼 입력칸이 아니면 카드를 통째로 표시하고
  4초 뒤 스스로 해제된다. `role="button"` + Enter/Space 키 대응.

### 규칙 배포가 필요했던 부분

`sleepAndMind` 는 `healthProfile` 과 달리 **키 화이트리스트가 엄격**하다.
`sleepHours` 를 규칙에 넣지 않으면 수면 시간 쓰기가 전부 거부된다.
→ `firestore.rules` 에 추가하고 배포까지 완료. 0~24 숫자 범위 검증 포함.

에뮬레이터 테스트(`tests/firestore-privacy-rules.emulator.test.js`)로 규칙 파일이
실제로 그 쓰기를 허용하는지 검증한다 — 배포 로그는 "파일이 릴리스됐다"까지만 말하고
"그 안의 규칙이 맞다"는 말해주지 못한다.

### 목적지 문자열 드리프트 방어

`focusId`/`tab` 은 문자열이라 누가 입력칸 id 를 바꾸면 클릭이 조용히 아무것도 안 하게
된다. `tests/le8-score.test.js` 가 모든 목적지가 `index.html` 에 실제로 존재하는지,
탭 id 가 진짜 `content-section` 인지 확인한다.
