가이드 설명 문장이 말하는 "몇 개 준비됐는지"는 아래 저장 막대가 이미 말한다.

## 바꾸는 것(후)

### 1. 갤러리 — 머리를 한 줄로

```
[📤 내 카드 공유]  [🔒 공개 설정 · 기본 공유 중]      ← 한 줄, 둘 다 누르면 그 아래로 펼쳐짐
[전체보기] [🥗 식단] [🏃 운동] [🧘 마음]               ← 필터 한 줄
(바로 피드 글)
```

- 없앰: HABIT FEED 글자, 「기록하고, 공유하고, 서로 응원하기」 제목, 설명 한 줄, ①기록 저장 ②인증 공유 ③친구 응원 단추, 「접기/펼치기」.
- 내 공유 카드(490px): 늘 열려 있던 것을 **접어 두고** 「📤 내 카드 공유」를 누르면 펼친다.
  기록 저장 뒤 「공유하기」 시트나 마음 탭 바로가기로 들어오면 지금처럼 바로 펼쳐서 보여 준다.
- 공개 설정(6칸 + 저장): **접어 두고** 「🔒 공개 설정 · (지금 상태)」를 누르면 펼친다.
  ⚠ 2026-11-18 대표 결정 「공유 설정은 늘 열어 둔다」와 부딪힌다 — 아래 확인 1번.
- 피드 머리의 「RECENT FEED」 글자와 「모두의 최근 인증」 제목은 화면에서 뺀다(필터 칩이 같은 말을 한다).
  한 사람 글만 볼 때는 지금처럼 「개인 필터 · 이름 · 전체 보기」 띠가 뜬다.
- 예상: 피드 첫 글이 **816px → 약 230px** (첫 화면 안).

### 2. 식단·운동·마음 — 가이드 카드를 없앰

- 보통 모드에서 가이드 카드(가이드 · 제목 · 설명 · 단추 3개)를 보이지 않게 한다.
  탭 맨 위는 바로 「🥗 식단 사진 올리기 (사진당 +10P…) ⓘ」 포인트 줄 → 업로드 칸 순서.
  사용법이 궁금한 사람은 포인트 줄 옆 ⓘ(사용법 2·3·4편 요약)를 누른다 — 이미 있다.
- **심플 모드(큰 글씨)는 그대로 둔다.** 심플 모드는 이 카드를 「오늘 식단 기록하세요」 큰 제목 + 큰 단추로 쓴다.
- 예상: 포인트 줄이 357px(펼침)/186px(접힘) → **132px**.

### 3. 다른 탭

- 내 기록(대시보드): 맨 위 「하나씩 기록 / 식단·운동·마음」은 안내가 아니라 기록 단추 판이라 그대로 둔다.
- 자산·프로필: 맨 위에 안내 카드가 없다 — 손대지 않는다.
- 런비커스 전용 커버, 첫 방문 소개 창은 손대지 않는다(다른 세션 작업).

### 영어 앱

`index.html` 을 고치고 `npm run build:en` 으로 `en/index.html` 을 다시 만든다.
새 문구는 단추 두 개뿐이고 `js/i18n-en.js` 에 키로 넣는다(「Share my card」, 「Privacy」).
