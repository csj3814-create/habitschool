## 식
```
2026-09 ~ : 활동포인트 + min(댓글×11 + 리액션×4, floor(활동포인트 × 0.30))
~ 2026-08 : days×10 + 댓글×3 + 리액션×1   (소스만 교정, 순위 규칙은 그대로)
```
배수 근거: 현행 상위 20명의 사회항 비중 13.7% 를 기록항이 days×10 → 활동 포인트로
바뀐 뒤에도 유지하도록 역산(배율 3.55).
