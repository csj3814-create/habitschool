# 새 회원: 가입 → 첫 기록 → 다음 기록 (설계안)

2026-11-07. 대표: "처음 가입한 회원이 원활하게 첫 기록을 남기고 다음 작업으로 이어갈 수 있도록 구성해보자."
방향은 정해져 있다 — **첫 기록은 식단 사진, 지금 눈앞에 있는 먹을 것.** 감사 한 줄은 앱의 장점이 아니라 쓰지 않는다.
앞선 설계: `tasks/2026-11-02_가입_안내_끝_첫기록_설계.md` (8절의 결정대로 v567 에 가입 안내 창이 "📸 오늘 먹은 사진 올리기" 로 바뀌었다).

## 1. 숫자 (운영 읽기 전용, 2026-11-07)

11/3 ~ 11/7 가입 23명(플레이 앱 13, 웹 10).

| | 명 |
|---|---|
| 가입 안내 창을 끝냄 | 21 |
| **첫 기록** | **4** (17%) — 모두 식단·운동 사진 |
| 기록이 없는 19명 중 **사진을 한 장이라도 골랐던 사람** | **0** |

- 사진은 고르는 순간 저장 전에 먼저 올라간다. 그래서 위 0명은 "사진을 골랐는데 저장에서 멈춘" 사람이 없다는 뜻이다.
  **사진을 고른 사람은 모두 첫 기록까지 갔다.** 끊기는 곳은 **사진 고르기 앞**이다.
- 가입 안내 창의 두 단추 중 어느 쪽을 눌렀는지는 서버에 남지 않는다(구글 애널리틱스에만 간다). 고르기 창을 열었다가 닫았는지도 모른다.
- 추정: 가입하는 순간 앞에 밥이 없어 "아직 안 먹었어요" → "다음 끼니 때 찍어서 올려 주세요" → 돌아오지 않는다.
  다음 날 이후 처음 기록한 사람은 23명 중 1명뿐이다.

## 2. 지금 흐름

1. 구글 로그인 → 동의
2. 가입 안내 창: "📸 오늘 먹은 사진 올리기" / "아직 안 먹었어요"
3. "아직 안 먹었어요" → **"다음 끼니 때 찍어서 올려 주세요"** + 돌아올 길(웹 앱 설치 / 플레이 앱 알림)
4. 사진을 고르면 식단 탭 → AI 분석 → "식단 저장하고 포인트 받기"
5. 첫 기록 결과 창: 이번 포인트, 가입 선물, 쿠폰까지 남은 점수, 돌아올 길 하나
6. (오늘 추가, 스테이징) 기록한 적 없는 회원의 식단 탭 맨 위 빨간 상자 "다음 식사를 기다리지 마세요"

3번이 오늘 정한 방향("다음 식사를 기다리지 말고 지금")과 반대다.

## 3. 바꿀 것 — 세 가지

### 3-1. 가입 안내 창: "다음 끼니" 대신 "지금 눈앞의 것"

- 큰 단추: **📸 지금 찍기** (지금과 같이 식단 탭을 열고 그 자리에서 카메라·사진 고르기)
- 설명: "밥이 아니어도 돼요. 지금 마시는 커피, 책상 위 간식도 한 장이면 첫 기록이에요."
- "아직 안 먹었어요" 를 **"나중에 할게요"** 로 작게 바꾼다. 누르면 두 번째 칸 없이 식단 탭으로 가고, 6번 빨간 상자가 맞이한다.
  두 번째 칸의 "다음 끼니 때 찍어서" 문구는 지운다. 돌아올 길(설치·알림)은 첫 기록 결과 창에서만 권한다.

### 3-2. 첫 기록 결과 창: 다음 할 일을 "다음 끼니 한 장" 으로

지금 큰 단추는 "이번 주 실천 확인하기" 다. 새 회원에게 "이번 주 실천" 은 아직 뜻이 없다.

- 제목: "첫 기록 완료! 다음 끼니도 한 장 찍으면 +10P" (식단 사진은 한 장 10P, 하루 30P 까지 — 지금 규칙 그대로)
- 큰 단추: 기기별 돌아올 길 — 플레이 앱 "다음 끼니(12시 또는 18시)에 알려 주세요", 웹 "홈 화면에 앱 설치하기" (지금 있는 것을 큰 단추로 올린다)
- 작은 단추: "오늘은 마치기"

### 3-3. 고른 방법이 서버에 남게 한다 (재기 위해)

- 가입 안내 창에서 "지금 찍기" / "나중에 할게요" 중 무엇을 눌렀는지, 고르기 창에서 사진을 실제로 골랐는지를
  회원 문서의 `settings` 에 한 번씩 적는다(날짜만). 그래야 2~3주 뒤 어디서 끊기는지 정확히 본다.
- `settings` 안의 새 칸이 규칙을 통과하는지 스테이징에서 첫 저장 뒤 확인한다. 막히면 규칙 배포를 따로 승인받는다.

## 4. 하지 않는 것

- 저장 단계 손보기 — 사진을 고른 사람은 모두 저장까지 갔다.
- 감사 한 줄·명상을 첫 기록으로 권하기.
- 첫 기록 안내 메일 — 그대로 둔다.
