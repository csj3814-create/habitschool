# 소개 페이지 대신 로그인 창 위 소개 레이어 (설계안)

2026-11-21. 대표 요청. 구현 전에 대표 확인을 받는다.

## 한 줄 요약

처음 온 사람도 **바로 로그인 화면**으로 간다. 그 위에 앱의 취지를 2~3줄로 말하는 **닫을 수 있는 작은 창**을 한 번 띄운다.
한국어 앱(`/`)과 영어 앱(`/en`) 모두 같은 방식.

## 지금

- 한국어: 처음 온 사람은 `/` 에서 긴 소개 페이지(`ko-public-page`)를 본다. `index.html` 머리 스크립트가
  `ko-landing` 을 붙인다(2026-11-03 입구 합치기). `/welcome` 주소는 늘 소개 페이지.
- 영어: 처음 온 외국어 기기 방문자는 `/` → `/en/welcome` 소개 페이지(`english-public-page`, `en-landing`)로 간다.
- 소개 페이지의 "시작하기"는 `/?start=1`(영어는 `/en`)로 가서 로그인 화면을 연다. 한 번 더 누르는 단계가 있다.

## 바꾸는 것

### 1. 소개 페이지는 남기고, 첫 화면에서만 뺀다 (2026-11-21 대표 확인)

대표: "앱의 취지를 더 알고 싶은 사람만 클릭해서 웰컴 페이지를 볼 수 있게 하고 아니면 간단하게 닫을 수 있게 하자."

- `/` 로 처음 온 사람에게 소개 페이지(`ko-landing`) 대신 로그인 화면 + 소개 창(`show-intro`)을 보인다.
- 처음 온 외국어 기기 방문자는 `/en/welcome` 대신 `/en`(로그인 화면 + 소개 창)으로 보낸다.
- 소개 페이지 `/welcome`·`/en/welcome` 은 그대로 둔다. 소개 창의 **"해빛스쿨이 더 궁금하다면"** 링크가 그리로 간다.
  소개 페이지의 시작 단추는 지금처럼 `/?start=1`·`/en` 이라 소개 창 없이 로그인 화면이 뜬다.

### 2. 소개 창 (로그인 창 위)

- 로그인 화면 위에 반투명 바탕 + 가운데 카드. **✕** 와 **시작하기** 단추. 둘 다 창만 닫는다 —
  닫으면 로그인 창이 그대로 보인다. 바탕을 눌러도 닫힌다.
- 한 번 닫으면 이 기기에서는 다시 띄우지 않는다(`localStorage` `habitschool-intro-seen-v1`).
- 판정은 지금처럼 **첫 화면 전에** 머리 스크립트에서 한다(깜빡임 없음).

문구(한국어 — 지금 소개 페이지에서 쓰던 말을 줄였다, 포인트·쿠폰은 넣지 않는다):

> 응급의학과 전문의 최석재가 만든 습관 학교
> **혼자 하면 잘 안 되는 좋은 습관, 같이 해요**
> 먹은 걸 사진으로 올리고 운동이랑 잠을 기록하면 AI가 바로 봐 줘요.
> 같이 하는 분들이 응원해 주고요. 돈 드는 거 전혀 없어요.
> [시작하기]  (안드로이드: [구글 플레이에서 앱 받기] + "웹에서 바로 시작하기")
> 해빛스쿨이 더 궁금하다면 → 소개 페이지

영어는 i18n-en 사전 키(`intro.*`)로:

> Made by an emergency physician
> **Good habits are easier together**
> Snap your meals, log movement and sleep, and AI gives quick feedback.
> Others cheer you on. Free to use.
> [Get started]

### 3. 창을 띄우지 않는 경우 — "할 일이 있어 온 주소"

지금 소개 페이지를 건너뛰는 기준을 그대로 쓴다.

| 들어온 길 | 소개 창 | 이유 |
|---|---|---|
| 이 기기에서 로그인한 적 있음 | 없음 | 이미 아는 사람 |
| 초대 `?ref=` | 없음 | 초대 배너가 같은 이야기를 이미 한다 |
| 병원 QR(`clinic-entry`) | 없음 | 병원 간판 화면이 따로 있고, 병원 화면에 앱 홍보를 얹지 않는다(의료법 환자 유인 걱정) |
| 공유·알림·메일·둘러보기·제휴(런비커스) 등 추적 꼬리표 말고 뭔가 붙은 주소 | 없음 | 무엇을 하러 왔는지 주소가 말한다 |
| 플레이 앱(`/app`, TWA) | 없음 | 앱을 깐 사람은 이미 마음먹었다 |
| 검색 로봇 | 상관없음 | 창은 로그인 화면 위에 덮일 뿐, 글은 그대로 읽힌다 |

### 4. 재는 것

`intro_layer_view`, `intro_layer_close`(✕/시작하기/바탕 구분)를 남긴다. 로그인 누름은 기존 `auth_start`.

## 건드리지 않는 것

- 로그인 창 자체(표어·노란 시작 상자·영상 세 편·초대 배너·병원 화면).
- 런비커스 `partner-cover` 부분(다른 세션 작업 중).
- 버전(?v·CACHE_NAME) — 운영 배포 때만.

## 안드로이드는 플레이 앱을 먼저 (2026-11-21 대표 확인)

대표: "구글플레이 앱이 걸음수도 자동으로 들어오고 헬스커넥트 연동도 많이 되어서 초기 사용자는 가능하면 구글플레이 앱을 권하는 게 맞는 것 같다."

- 안드로이드(`intro-android`, 초대 코드가 없을 때)에서는 소개 창의 큰 단추가 **구글 플레이에서 앱 받기**,
  그 아래 **웹에서 바로 시작하기**(창만 닫음). 한 줄 덧붙임: "앱에서는 걸음수와 수면이 자동으로 들어와요."
- 카카오톡 같은 앱 안 브라우저는 소개 페이지처럼 플레이 앱을 바로 연다(`buildPlayStoreIntentUrl`).
- 그 밖의 기기는 큰 단추 **시작하기** 하나.

## 검증

- `npx vitest run` 전체. `/` 첫 방문 테스트(`korean-landing`, `play-first-screen-language`)는 소개 창 기준으로 고쳐 쓴다.
- `node scripts/snapshot-korean-text.mjs`, 스타일을 바꾸므로 `node scripts/generate-clinic-theme.js`, `npm run build:en`.
- 로컬 휴대폰 크기 화면에서: 한국어 `/` 첫 접속, 영어 `/en` 첫 접속, 닫은 뒤 다시 열기, `?ref=` 로 들어오기.
