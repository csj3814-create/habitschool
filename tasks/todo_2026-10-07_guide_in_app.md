# 사용법 연재를 앱 안으로 — ⓘ 요약 방식 (2026-10-07)

## 결정 (사용자, 2026-10-07)
- 사용에 불편을 주지 않는 선에서, **기능 버튼(또는 카드 제목) 오른쪽에 동그라미 속 물음표(ⓘ/?)** 를 둔다.
- ⓘ 를 누르면 **요약**을 보여 주고, 요약의 **"자세히"** 를 누르면 **브런치 글**을 연다.
- 따라서 저절로 뜨는 안내(팝업·처음 만나는 순간 카드)는 만들지 않는다. 회원이 궁금할 때 스스로 누르는 방식만 쓴다.

## 동작
1. ⓘ 는 작고 옅게(16px 아이콘, 터치 영역은 32px). 기존 버튼 모양·위치·간격은 바꾸지 않는다.
2. 누르면 아래에서 올라오는 시트: 편 제목, 요약 2~3줄(원고 문장 그대로), 캡처 1장(선택), 버튼 두 개 **[자세히 — 브런치에서 읽기]** · **[닫기]**.
3. "자세히" 는 새 창으로 브런치 글을 연다. 안드로이드 앱(TWA)에서는 크롬 탭으로 열려 앱으로 바로 돌아올 수 있다.
4. ⓘ 가 버튼 안이나 옆에 붙어도 **그 버튼을 누른 것으로 처리되지 않게** 한다(이벤트 전파 막기). 예: 내 기록 탭 점수 요약은 카드 전체가 버튼이다.
5. 아직 게시하지 않은 편은 ⓘ 를 숨긴다. 지금은 1~6편.
6. 영어 앱(`/en`)에는 ⓘ 를 보이지 않는다(글이 한국어뿐).
